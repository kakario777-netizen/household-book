# 가계부

카드 결제 문자를 읽어 자동으로 정리하는 안드로이드 가계부 앱.

- 달력: 날마다 쓴 돈, 이번 달 합계, 정기결제 예정일 표시
- 통계: 분류별(식비·외식·카페 등) 비율, 카드별 금액, 최근 6개월
- 정기결제: 매달 비슷한 날·금액으로 나가는 결제 자동 찾기
- 위젯: "오늘 ○○원 쓰셨어요" + 이번 달 합계
- 분류는 가게 이름으로 자동, 고치면 그 가게는 계속 그 분류로

결제 내역은 폰 안에만 저장됩니다 (서버 전송·구글 백업 없음).
